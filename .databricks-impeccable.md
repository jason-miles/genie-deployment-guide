## Design Context

### Surface type
Static documentation site (HTML, CSS, vanilla JS) on GitHub Pages; also servable by Apache httpd.

### Audience
Field (Databricks SAs and DSAs) using it as a delivery reference for Hive metastore to Unity Catalog migrations.

### Theme
Both. Light is the default; dark follows the system setting and a manual toggle.

### Use case
Follow nine migration steps in order, copy commands, and confirm each step's gate before moving on.

### Brand (locked)
- Palette: Lava 600 #FF3621 (10% accent), Navy 900 #0B2026, Light #F9F7F4
- Typography: DM Sans 400/500/700 + DM Mono
- Components: Du Bois first
- Voice: Databricks editorial-plain (no superlatives, plain statements)

### Additional constraints
- WCAG AA minimum.
- No build step: plain files only, no external network dependencies (the Apache config sets a strict Content-Security-Policy).
- Public repo: no customer names or internal links.
